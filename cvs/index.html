Put:

  export CVSROOT=:pserver:$USER@130.242.129.140:/var/cvs/brandenb

and say:

  cvs login

This should work correctly if $USER corresponds to the correct UserId
that I entered for you. Then you give the password.

Next, you say

  cvs co 

which is the path I gave you. You can move this directory
or the entire path anywhere you like. All that cvs cares about
is the CVS directory inside the directory.

Other useful commands:

  cvs log paper.tex|m

to see version numbers, and then

  cvs diff -r 1.16 -r 1.17 paper.tex | m

to see the differences between particular ones.

    New CVS

    The new server uses SSH for authentication and to check out, say, tex/inputs, you would do 
      cvs -d :ext:cvs@norlx65.nordita.org:/srv/cvs/brandenb checkout tex/inputs/
    This will only work after you set up an SSH key, though, see the following instructions. We recommend creating a separate SSH key for this (though in theory you could use your standard key). 
      0. In your .cshrc (and correspondingly for bash), put
         setenv CVS_RSH ssh
  1. Generate an SSH key
         ssh-keygen -f ~/.ssh/cvs-nordita-key
  2. Send the file ~/.ssh/cvs-nordita-key.pub to Axel via email.
  3. Axel will add an entry
         no-port-forwarding,no-X11-forwarding,no-agent-forwarding,no-pty,command="/usr/bin/cvs server" ssh-rsa AAAA[...] user@host
     to the file ~cvs/.ssh/authorized_keys
     Once this is done, you can proceed:
  4. Add the key to your ssh agent:
         ssh-add ~/.ssh/cvs-nordita-key
     You'll need to repeat this if you login afresh (but you know that
     from the other SSH keys you are using).
  5. Use CVS. Note that the CVS root
         :pserver:dobler@norserv.nordita.dk:/home/brandenb/CVS
     is now replaced by
         :ext:cvs@norlx65.nordita.org:/srv/cvs/brandenb
     (a) To check out from scratch, use something like
           cvs -d :ext:cvs@norlx65.nordita.org:/srv/cvs/brandenb checkout idl/pro
     (b) If you have set the CVSROOT environment variable, adapt it to
         :ext:cvs@[...] (see above)
     (c) To continue existing checkouts from the old server, you'll need
         to recursively adapt the CVS/Root files.
    Once you are in, check out Wolfgang's notes from etc/cvs.
